# 1.4.4：四套字体方案，设置里切换

> **已被 1.4.5 取代**：用户的意思不是“挑一套整体字体”，而是同一页里分层使用不同字体。四选一的切换项在 1.4.5 里已去掉，见 [1.4.5 报告](../1.4.5/REPORT.md)。

2026-10-19 用户看完 1.4.3：「字体不行，全是黑体，不好看」。上一版把相位原来的系统字体换成了思源黑体，看起来和系统黑体几乎一样，用户不满意。之前用户说过原来「全是楷体」也不符合风格，所以两头都不要。

## 做法

字体好不好看是主观的，我不再替用户猜一款，而是把几套备选都放进这个测试版，用户在手机上切着看，定了再把没选中的拿掉。

设置页新增「界面字体」，四选一，选完立刻生效并记住：

| 方案 | 时间数字和标题 | 正文和按钮 | 特点 |
|---|---|---|---|
| 黑体 | 思源黑体 | 思源黑体 | 上一版，中性、清楚 |
| 宋黑（默认） | 思源宋体 | 思源黑体 | 大时间和标题有书卷气，小字仍清楚 |
| 全宋 | 思源宋体 | 思源宋体 | 书卷气最重，小字偏细 |
| 潮流 | 得意黑（斜体） | 思源黑体 | 最有个性，偏活泼 |

字体来源和许可（均为 SIL OFL 1.1，全文在 `licenses/`，应用内「开源许可」可看）：

- Noto Sans SC、Noto Serif SC：本机已有的可变字体，裁剪后保留 300–700 字重。
- Smiley Sans 得意黑 v2.0.1：从作者 GitHub 发布页下载。它声明了保留字体名（Smiley、得意黑），裁剪后的版本按许可要求改名为 Phase Display SC。
- 三个文件各约 4000 个字形，共约 5.5 MB，APK 增大约 3 MB。字库之外的生僻字由系统字体兜底。
- 生成脚本 `tools/build_phase_font.py`（需要 fontTools）；中文字体里的间隔号“·”原本是全角，已缩窄。

没有采用的：霞鹜新致宋、新晰黑（许可是 IPA Font License，裁剪重发的条件更麻烦）；霞鹜文楷（楷体，用户明确不要）。圆体类（柔和）这次没有找到许可明确的中文字体。

## 验证

- 编译 `:app:assembleDebug :app:assembleDebugAndroidTest :app:assembleCoexist` 成功。
- 模拟器上把「宋黑」「全宋」「潮流」逐个切过，首页和设置页看图确认：大时间字重、间隔号宽度、按钮文字都正常；「潮流」的大时间因为只有一个字重，看起来比其他方案粗。
- 新增自动测试：选中「全宋」后设置页立即显示选中、偏好已保存，重新打开应用仍然是「全宋」，再改回「黑体」也保存。结果见 [运行摘要](evidence/phase144-font-summary.json)。
- 按用户要求，没有在手机上跑测试，只安装；没有在手机上启动相位。

共存包 `app/build/verification/phase-1.4.4-test.apk`，20,551,798 字节，SHA-256 `f671d45e62fdfd6cf53065cfc40f75471c269dd9eeded7863cb2197014c2892f`；AAPT 核对 `com.example.smartalarm.test / 1.4.4-test (21) / 相位·测试版`，包里含三份字体；签名证书与 1.4.3 相同，已覆盖安装到手机。

## 没做 / 待定

- 最后只留一套：用户选定后，删掉没选中的字体和切换项，APK 会小回去。
- 圆体、其他中文字体没有试；如果四套都不满意，需要用户给方向（例如“更圆润”“更像某个 APP”），再找。
- 手机上的真实观感没有看过。
