# 1.4.3：字体与界面细节

2026-10-19 用户要求：不改变整体风格基调，优化界面细节；现在的字体全是楷体，不符合风格，重做字体集；不在真机上测试，直接安装到手机，由用户自己验收。

## 字体

**原因（推断，未在手机上看到）**：相位以前不带任何字体，全部交给系统默认字体。我读了这台手机（OPPO PJZ110，ColorOS 16）的系统字体配置，默认简体中文是 OPPO Sans，是黑体类，并不是楷体。所以用户看到的楷体多半来自手机里选的系统字体，相位只是原样跟着变。我没有在手机上启动相位，也没截屏，这一点没有证实。不管来源是什么，相位应当有自己的字体，不随系统字体变化。

**做法**：随应用带一套无衬线字体 Noto Sans SC（可变字重），中文和数字都由它渲染。
- 来源与许可：本机已有的 Noto Sans SC 2.04 可变字体，SIL OFL 1.1，随附 [licenses/NotoSansSC-OFL.txt](../../licenses/NotoSansSC-OFL.txt)，并写入 `THIRD-PARTY-NOTICES.md` 和应用内「开源许可」。
- 裁剪：保留 300–700 字重、约 4000 个字形（应用源码里出现的全部汉字，加 GB2312 一级汉字与常用标点）。文件 1.88 MB，装进包后 APK 约增加 1.2 MB。
- 字库之外的生僻字仍由系统字体兜底；时钟名称等从系统读来的文字可能出现，属于预期。
- 间隔号“·”原字形是全角，“5 个周期 · 7 小时”中间会空出一大块，裁剪时缩窄成约 0.38 个字宽。
- 可重新生成：`tools/build_phase_font.py`（需要 fontTools）。
- 字阶重新定过：时间数字等宽；正文行高放宽到约 1.55 倍；小字号从 12sp 提到 13sp；按钮文字原来被「小节标题」的宽字距占用，现在分开，按钮字不再被撑开。

## 界面细节

整体仍是月光夜空的深蓝底、淡蓝主色，没有换配色、没有换版式。

- **首页**
  - 主卡片：标题只写一次（以前“7 小时 55 分”会重复出现并折行落单一个“分”字）；时间轴起点改为空心圆，原来那段虚线看起来像污点；左右标注改为“02:48 躺下”“11:03 起床”，两端对称。
  - 「设为系统闹钟」按钮上移到时间轴后面，不再被一大段说明挤到屏幕下面；“时间可以微调”的说明放到按钮之后，放进一块淡色底板里。
  - 候选列表：选中行是圆角色块，不再是贴边的直角条；醒来状态用圆点加文字（以前只有一个圆点，靠颜色区分）；“推荐”标记略放大。周期类候选标题里已写总时长，不再重复“全晚睡”。
  - 「计划几点睡」：时间是主角，“跟随现在”降为说明，右侧加箭头；开关关闭时轨道可见。
  - 小节标题与卡片之间的距离收紧，标题更靠近自己的卡片。
- **设置页**：第一张卡片原来是系统默认的灰紫色，和其他卡片不一致，已统一；「普通 / root」改成与首页滑块同族的分段选择；选择时钟改成一行加箭头；备份区原来是两个裸文字按钮，现在有卡片和标题；链接按钮和标题左对齐，点按区域不小于 48dp。
- **全局**：补全了 Material 的容器颜色。以前卡片、对话框、开关会退回默认灰紫色；现在都按夜空配色。时间选择等对话框底色统一。
- **历史页**：周/月/热力切换补上选中状态的无障碍标记，按钮略放大；小节标题统一。
