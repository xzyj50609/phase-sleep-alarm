# 1.4.6：模式名、状态行、标题不再用黑体

2026-10-19 用户反馈 1.4.5：「普通模式还有标题别用这个黑体，就像『正常』『爽睡』『小睡』这几个模式，用黑体就会显得很笨重。」

## 原因

1.4.5 把字体分成三个角色，但“黑体”管的范围太大：按钮、模式滑块、状态行（“普通模式 · 尚未选择时钟”）、说明、时间轴刻度、各行标题，凡是没特别指定的小字号全落在黑体上。黑体笔画粗、字面大，在小而短的标签上显得笨重。

## 改动

- **黑体收窄到只管成段的说明文字**：首页“时间可以微调”的两段话、设置页的解释文字和底部说明、历史页顶上那句“这里记录计划睡眠与闹钟确认……”。
- **其余全部改用宋体**：模式名（正常、爽睡、小睡、上课、保早餐）、状态行（“普通模式 · 尚未选择时钟”，同时放大一档）、顶部日期行、所有按钮和文字链接、分段选择（普通 / root）、各行标题（睡眠周期长度、选择普通模式时钟……）、对话框正文、时间轴刻度、历史页读数。
- 标题仍是斜体招牌体（得意黑）：“相位”字样、页面标题、卡片标题、对话框标题。
- 宋体的字距略放开一点（0.2sp），小字号在深色底上更透气。

所以现在是两个主要的声音：宋体管“字”和“数”，斜体招牌体管“标题”；黑体只在长段说明里出场。

## 验证

- 编译 `:app:assembleDebug :app:assembleDebugAndroidTest :app:assembleCoexist` 成功。
- 模拟器上用 1.15 倍字体看首页和设置页：模式滑块的名字、状态行、日期行、按钮、时间轴刻度都是宋体，不再有黑体的粗重感；斜体标题和大时间保持不变。
- **自动测试这版没有跑**：编完装好手机后，模拟器进程在电脑内存紧张时消失了（`adb devices` 里只剩手机），我没有在内存只剩 1.3 GB 的机器上重新拉起模拟器。1.4.6 与 1.4.5 相比只改了字体归属（字阶换字体、几处显式指定），没有改布局、结构或逻辑；最近一次自动测试是在 1.4.5 上（见 [1.4.5 报告](../1.4.5/REPORT.md)）。模拟器恢复后建议补跑一遍整套。
- 按用户要求没有在手机上测试，只安装；共存包 `app/build/verification/phase-1.4.6-test.apk`，20,535,414 字节，SHA-256 `28e1a74856418b133d621f3dafa123a1aae9c5e5ce52ebddd343e92fdb05d59a`，`com.example.smartalarm.test / 1.4.6-test (23) / 相位·测试版`，已覆盖安装到手机。

## 没做 / 待定

- 手机上的观感没有看过。宋体小字笔画细，如果在手机上觉得偏弱，可以把正文级别（14–16sp）加到 Medium 字重，或把状态行的颜色提亮一点，不需要换回黑体。
- 如果希望成段说明也不用黑体，只需把 `PhaseFonts.body` 的几处引用去掉。
