# 相位 Phase

按睡眠周期推荐起床时间的 Android 小工具。点一下，它算出“现在睡的话，几点醒最轻松”，再把选中的时间交给手机自带的时钟去设闹钟。完全离线，没有联网权限。

> 界面目前只有简体中文。

## 它做什么

- 以“现在 + 入睡所需时间”作为睡着的时刻，按睡眠周期（默认 95 分钟，可在设置里调 80–120 分钟）列出几个推荐的醒来时间，并说明为什么推荐。
- 有几种场景：正常、爽睡（补眠）、小睡、上课（赶最晚起床点）、保早餐（贴近目标起床时间），以及“中途必须醒一次”的必醒时刻。
- 选中一个时间，点“设为系统闹钟”，相位把小时和分钟交给你手机里的时钟应用。
- 历史页记录你确认过的计划，只是计划，不是测得的睡眠数据。

## 下载与安装

到 [Releases](../../releases) 下载最新的 APK 安装。需要 Android 8.0 及以上（API 26）。第一次安装可能需要允许“安装未知来源应用”。

## 设闹钟的两种方式

**普通模式（默认，所有人都用这个）**：相位用 Android 标准的“设置闹钟”接口交给时钟，不需要特殊权限。针对已知会直接创建的 ColorOS 接收入口，1.4.1 改为打开新建页，由你手动填写推荐时间并保存；其他时钟保留预填请求，实际表现取决于厂商实现。相位无法读取最终结果，返回后需要你确认是否保存。

**root 模式（实验性，普通用户请勿开启）**：只适配 Android 16、ColorOS 时钟 16.19.14、简体中文的主用户空间，需要 root 授权，会直接读写系统时钟里的闹钟。目前只在作者的一台手机上验证过，当前版本没有在真实 root 手机上回归。

## 1.4.0 开发版

本分支的 1.4.7 (24) 尚未公开发布，root 真机写入仍待用户验收：

- 选择 Root 后先申请并核验授权，成功才进入；拒绝、超时或不兼容时保留普通模式。管理器不弹窗时会提示去手动授权后重试。
- 推荐卡片支持左右滑动并带动上方模式：轻划不切换，拖过一定距离或明显快划才切，切换带渐变；垂直滚动仍用于浏览页面。变更和验收边界见 [1.4.1 报告](docs/1.4.1/REPORT.md)、[1.4.2 报告](docs/1.4.2/REPORT.md)。

- 1.4.3 起相位自带字体（SIL OFL 许可的裁剪版），不再随系统字体变化；1.4.5 起字体分层、1.4.6 起宋体管字与数、斜体招牌体管标题、黑体只留给成段说明；首页与设置页的排版和配色细节做了统一，详见 [1.4.3 报告](docs/1.4.3/REPORT.md)。

- root 模式下，完整周期候选提供“睡得快 / 按预计 / 躺得久”三个可直接设置的时间。“按预计”保留原始计算时间，不取整；定点候选仍只有一个时间。
- 完整周期候选增加“时间可以微调”的提示。偏移来自计算模型，是可调的误差假设，不是测得的睡眠数据或医学保证。
- 最近一次已确认的操作距今 15 分钟至 4 小时时，首页提供“从现在重算”。重算会只读检查旧闹钟；确认还开着或没能确认时提醒用户自行查看，不删除、关闭或修改旧闹钟。
- 模式切换条支持点选和横向拖动，松手后才更新模式；版本和离线许可全文移到设置底部的“关于相位”。包含新的 C2 图标及单色版。

本轮验证与真机待验收事项见 [1.4.0 验证报告](docs/1.4.0/REPORT.md)。

## 已验证与未验证

普通模式的交接和之后熄屏响铃界面，在这些设备上验证过：

- Google Pixel 8（Android 16，Google 时钟）
- OPPO CPH2195（Android 13，ColorOS 时钟）

以上设备验证的是 1.3.0；1.3.1 只改了界面文字、root 入口的实验性提示和构建配置，没有改推荐算法和交接逻辑。另外在 Android 8 到 17 的模拟器上跑过自动化测试。三星、小米、华为等品牌的原厂时钟没有验证过，可能表现不同。没有测过物理扬声器的响铃声音。

## 已知限制

- 只支持手机主用户空间；工作资料、应用分身、第二空间等会被拒绝。
- 普通模式下，部分时钟每次设置都会多出一条同样时间的闹钟，是系统时钟自己的行为。
- 系统浅色模式下状态栏图标对比度偏低。
- 包名为 `com.example.smartalarm`，是有意保留的历史名称。

## 自己构建

环境：JDK 17、Android SDK 35。第一次构建需要联网（Gradle 依赖，其中 libsu 来自 JitPack）。在项目根目录建 `local.properties`，写 `sdk.dir=你的SDK路径`（用 Android Studio 打开会自动生成）。

```text
./gradlew :core:test :app:assembleDebug
./gradlew :app:assembleRelease
```

没有正式签名时，release 包会用 debug 签名，只适合自己安装使用。要用自己的证书签名，把 `PHASE_SIGNING_DIR` 环境变量指向一个目录，里面放 `phase-release.p12` 和 `store-password.txt`（alias 为 `phase`）。

`core/` 是纯逻辑（睡眠计算与操作状态），`app/` 是界面和时钟交接。`tests/clockfixture` 是合成的“假时钟”，用于模拟器测试，`tests/upgradeprobe` 是升级兼容探针。
